# Ishwar Jadhav — Developer Portfolio

A responsive React + Vite portfolio inspired by the mobile reference video: dark charcoal background, red/orange accents, compact navigation, project cards and mobile-first layout.

## Run on your laptop

1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted `ishwar-portfolio` folder in VS Code.
4. Open Terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Personalize before publishing

- In `src/App.jsx`, replace `your.email@example.com` with your real email address.
- Replace the LinkedIn placeholder URL with your profile URL.
- Add real deployed project URLs when available.

## Build for deployment

```bash
npm run build
```

Upload the project to GitHub, then import the repository into Vercel. Use the default Vite settings.
